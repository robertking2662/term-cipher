Blazing-fast terminal checksum calculation and hashing tool written in idiomatic Rust.

## Features
- ⚡ **Zero Allocations**: In-place byte streaming.
- 🦀 **Memory Safe**: Guaranteed zero data-races by the Rust compiler.

```bash
cargo run -- "Test Data String"
```
